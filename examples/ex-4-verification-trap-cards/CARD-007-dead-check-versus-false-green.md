# 🃏 CARD-007 — ***죽은 검사 ⊥ 거짓 초록은 다른 칸이다***

> 함정 카드 · 재료 · 2026-09-21
> 🔒 밟아야 생기는 함정입니다. ⑤는 **붙여넣어 돌리면 빨강**입니다.
> 📎 이 카드는 **CARD-001「게이트가 통과시킨다」의 ★반례 짝**입니다 — 같은 고장, **rc 하나가 갈랐습니다.**

## ① 제목 (기전으로)
**검사가 죽는 것과 검사가 거짓말하는 것은 다른 사건이다.**
같은 고장(대상 0건)이 나도 — `exit 0`은 「통과」로 읽히고, `exit 3`은 **사람을 부른다.**

## ② 겉보기
```
· 게이트가 ★초록이다. 로그엔 「✅ 통과」.
· ⊥ ★검사한 파일 수를 ★아무도 안 봤다 — ★0 이었다.
· 그리고 ★그 0 은 ★작업 디렉터리에 따라 ★나타나기도 ★사라지기도 한다.
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 만든 트리 : 검사 대상 `.py` ★2 (src) ＋ 제외 대상 `.py` ★2 (vendor) ＝ ★4
· ⛔따옴표 없는 제외 목록이 ★두 파일로 ★글로브 확장 ⇒ find 식 ★파손
· `2>/dev/null` 이 에러를 ★삼킴 ⇒ ***★센 수 ＝ 0***
· 순진한 판 ⇒ 「✅ 통과」 · rc ***★0***      ⇐ 🔴 ★거짓 초록
· 정직한 판 ⇒ 「⏸ 잴 것이 없습니다」 · rc ***★3***  ⇐ ⭕ ★죽었지만 ★정직
· 재현 rc ★1 (★거짓 초록을 잡았으므로)
```

## ④ 기전
목록을 **따옴표 없이** 변수에 담아 셸 명령에 넣으면 → 단어분할 → 그중 `*`가 든 낱말이 **글로브로 확장**된다.
확장 결과가 여러 개면 명령의 **문법 자체가 달라진다.** 그때 표준에러를 버리면 **고장이 침묵**하고,
남는 것은 **「0건」이라는 정상적으로 보이는 수**다.
⇒ 그 0 을 `exit 0`으로 바꾸는 순간, **죽은 검사가 통과 도장을 찍는다.**
⇒ 🔒 ***「잴 것이 없음」은 「통과」가 아니다*** — 그 한 갈래가 있으면 **죽어도 거짓말은 안 한다.**

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```sh
d=$(mktemp -d); cd "$d"; mkdir -p proj/src proj/vendor
for f in proj/src/a.py proj/src/b.py proj/vendor/x.py proj/vendor/y.py; do echo x > "$f"; done
SKIP="-path proj/vendor/* -o -path proj/.git/*"        # ⛔따옴표 없이 쓰게 됨
n=$(find . \( $SKIP \) -prune -o -name '*.py' -print 2>/dev/null | wc -l)
echo "센 수 = $n  (★실제 대상은 2)"
if [ "$n" -eq 0 ]; then echo "순진한 판 ⇒ ✅ 통과 (rc 0)  ← 🔴 거짓 초록"
                        echo "정직한 판 ⇒ ⏸ 잴 것이 없습니다 (rc 3) ← ⭕ 죽었지만 정직"
                        cd /; rm -rf "$d"; exit 1
fi
echo "식이 살아 있습니다 (n=$n)"; cd /; rm -rf "$d"; exit 0
```
```
[측] 출력 : 센 수 ＝ ★0 (실제 대상 2) ⇒ ★거짓 초록 재현 ⇒ rc ★1
```

## ⑥ 처방
```
① 목록은 ★배열로 — ⛔문자열에 담아 ★따옴표 없이 펼치지 않는다
② ★표준에러를 버리기 前에 ***★죽음을 드러낼 계기***를 둔다 — ⛔`2>/dev/null` 자체가 독이 아니다
③ ★세 갈래를 만든다 : 통과 ⊥ 실패 ⊥ ***★잴 것이 없음(별도 rc)*** — ★이 한 갈래가 ★사람을 부른다
④ ★검사 건수를 ★출력에 ★항상 찍는다 — ★0 이 ★눈에 보이게
⑤ ★작업 디렉터리를 ★바꿔 ★같은 수가 나오는지 본다 — ★글로브는 ★CWD 를 먹는다
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★같은 제외 목록을 ★여러 검사가 ★공유하고 있으면 ⇒ ★한 곳을 배열로 고쳐도 ★나머지가 옛 꼴로 돈다.
> ⇒ ★그 목록을 ★읽는 자리를 ★전부 세고 시작한다.
> ```

## ⑦ 이 카드가 주장하지 않는 것
```
⛔ 「죽은 검사는 괜찮다」 — ⛔아니다. ★죽은 채로 오래 서 있었다
⛔ 「`2>/dev/null` 을 쓰지 말라」 — ★쓸 자리가 있다. ★문제는 ★그 앞에 ★계기가 없는 것
⛔ 「rc 3 이면 안전」 — ★rc 3 은 ***사람을 부르는 데까지***다. ★부름을 ★아무도 안 받으면 ★같다
⛔ 「내 환경에선 안 난다」 — [측] ★작업 디렉터리에 따라 ★나기도 ★안 나기도 한다
```
