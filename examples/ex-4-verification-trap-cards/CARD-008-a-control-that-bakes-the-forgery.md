# 🃏 CARD-008 — ***통제가 위조를 「기대되는 모양」으로 박는다***

> 함정 카드 · 재료 · 2026-09-21
> 🔒 밟아야 생기는 함정입니다. ⑤는 **붙여넣어 돌리면 빨강**입니다.

## ① 제목 (기전으로)
**자체 시험의 fixture 기본값이 「통과하도록」 만들어져 있으면 — 그 시험은 위조를 정답으로 배운다.**
⇒ 결과는 `n/n 통과`. 그런데 그 n 은 **제작자가 의도한 동작의 재현 횟수**이지, 판정이 아니다.

## ② 겉보기
```
· 자체 시험 ★전부 초록. 표에 ★n/n 이 찍힌다.
· 도구는 ★필수 승인 필드를 ★요구하고 있고 · ★빈 값은 ★정확히 거부한다.
· ⊥ ★그 필드에 ★아무 값이나 넣으면 ★통과한다 — ★시험이 ★그 값을 ★쓰고 있었다.
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 제작자 fixture(기본값 ＝ ★「0」 64자) ⇒ rc ★0 ⇒ ★통제가 「통과」로 기록
· 적대 fixture ★4 : 0 64자 · 그럴싸한 해시 · 산문 · ★실제 승인
    순진한 판   ⇒ 0 / 0 / 0 / 0     ⇐ 🔴 ★위조 ★3건 통과
    대조하는 판 ⇒ 7 / 7 / 7 / ★0    ⇐ ⭕ ★실제 승인만 통과
· 재현 rc ★1
```

## ④ 기전
통제를 쓰는 사람은 **도구가 돌아가는 모습을 보려고** fixture 를 만든다. 그래서 fixture 의 기본값은
**「통과하는 값」**이 된다. 그 값이 *형식만 갖춘 가짜*여도 상관없다 — 목적이 *돌아가는 것*이었으니까.
그 다음부터 통제는 **그 가짜를 정답으로 들고** 매번 초록을 낸다.
⇒ 🔒 ***통제의 분모에 「나 아닌 사람」이 0 이면, 그 초록은 내 습관의 사본이다.***

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```python
import hashlib, sys
APPROVALS = {"a1": "approved by reviewer"}
def install(req):                       # ⛔필드가 있으면 통과
    return (7, "INCOMPLETE") if not req.get("approval_sha256") else (0, "INSTALLED")
def install_strict(req):                # ⭕대장과 대조
    want = {hashlib.sha256(v.encode()).hexdigest() for v in APPROVALS.values()}
    return (0, "INSTALLED") if req.get("approval_sha256", "") in want else (7, "NOT_BOUND")
def mk_req_producer(**kw):              # ★제작자 fixture — 기본값이 위조
    d = {"target": "bin/tool", "approval_sha256": "0" * 64}; d.update(kw); return d
ADVERSARIAL = [
    ("0 64자",       {"approval_sha256": "0"*64}),
    ("그럴싸한 해시", {"approval_sha256": "de"*32}),
    ("산문",         {"approval_sha256": "see note"}),
    ("실제 승인",     {"approval_sha256": hashlib.sha256(APPROVALS["a1"].encode()).hexdigest()}),
]
print("제작자 fixture ⇒ rc", install(mk_req_producer())[0], " ← 통제는 이것을 「통과」로 적었습니다")
rows = [(n, install(r)[0], install_strict(r)[0]) for n, r in ADVERSARIAL]
for n, a, b in rows: print(f"{n:<12} 순진 {a}  대조 {b}")
bad = [n for n, a, b in rows if a == 0 and b != 0]
print(f"🔴 순진한 판이 통과시킨 위조: {bad} ({len(bad)}건)")
sys.exit(1 if bad else 0)
```
```
[측] 출력 : 위조 ★3건 통과(0 64자 · 그럴싸한 해시 · 산문) ⇒ rc ★1
```

## ⑥ 처방
```
① ★적대 fixture 를 ***★먼저*** 쓴다 — ★기능 fixture 보다 ★앞에
② ★fixture 기본값을 ***★거부되는 값***으로 둔다 — ★통과는 ★명시적으로만
③ 통제 영수증에 ***★누가 만든 통제인지***를 적는다 ⇒ ★「n/n」을 ★게이트 낱말로 쓰지 않는다
④ ★독립 재현을 ★따로 청한다 — ⭐***재는 손과 채점하는 손을 가른다***
⑤ ★필수 필드는 ★존재가 아니라 ***★대조***로 검사한다(대장·서명·형태)
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★같은 fixture 파일을 ★여러 통제가 공유하면 — ★기본값을 고치는 순간 ★그 통제들이 ★전부 빨강이 된다.
> ⇒ ★그게 ★정상이다. ⛔그 빨강을 ★「fixture 가 깨졌다」로 읽고 ★되돌리지 않는다.
> ```

## ⑦ 이 카드가 주장하지 않는 것
```
⛔ 「자체 시험이 쓸모없다」 — ★제작자 의도의 재현으로는 ★유효하다. ★그 이름으로 부르면 된다
⛔ 「적대 fixture 를 붙이면 끝」 — ★그것도 ★내가 쓴다. ★독립 재현이 ★따로 필요하다
⛔ 「위조가 실제로 쓰였다」 — ★이 카드는 ★가능성까지다(★쓰인 흔적은 ★별도로 세야 한다)
⛔ 「숫자가 크면 안전」 — ★45/45 도 ★분모가 내 습관이면 ★1/1 과 같다
```
