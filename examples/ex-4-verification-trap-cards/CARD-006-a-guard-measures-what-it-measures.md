# 🃏 CARD-006 — ***가드는 자기가 재는 것만 막는다***

> 함정 카드 · 재료 · 2026-09-18
> 🔒 밟아야 생기는 함정입니다. ⑤는 **붙여넣어 돌리면 빨강**입니다.

## ① 제목 (기전으로)
**「한 번에 여러 개 금지」 가드가 서 있는데 — 루프가 ★하나씩 주면 한 번도 안 걸린다.**
⇒ 가드는 **막으려던 것**(사람이 확인했는가)이 아니라 **재기 쉬운 것**(인자 개수)을 재고 있었다.

## ② 겉보기
```
· 위험한 일괄 처리를 막으려고 ★가드를 달았다. 시험해보면 ★잘 막는다.
· 몇 주 뒤, 같은 일이 ★또 일어난다 — ★가드는 ★한 번도 안 울었다.
· 로그를 보면 ★거부 ★0 건. ⇒ 「가드가 잘 서 있다」로 읽힌다.
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 대상 ★5건
· 한 번에 5개 지정 ⇒ ★거부 ★1/1        (★가드가 ★작동한다)
· ★루프로 1개씩 ×5  ⇒ ★거부 ***★0/5***  ⇒ ***★확인 없이 처리된 것 ★5***
· ★증거 기반 가드   ⇒ ★거부 ★5/5        (★확인한 것이 ★0 이므로)
· 재현 rc ★1
```

## ④ 기전
가드를 달 때 우리는 **사고의 모양**(한 번에 왕창)을 보고 조건을 쓴다. 그런데 사고의 **원인**은
모양이 아니라 **확인의 부재**다. 개수는 *관찰하기 쉽고* 확인은 *관찰하기 어렵다.*
⇒ 그래서 가드는 **대리지표**를 재게 되고, 대리지표는 **다른 경로로 같은 결과에 도달하는 것**을 못 막는다.
⇒ 🔒 ***가드는 자기가 재는 것만 막는다*** — 막으려던 것과 재는 것이 같은지 **말로 적어 보아야** 드러난다.

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```python
import sys, hashlib
ITEMS = [f"item-{i}" for i in range(1, 6)]
confirmed = set()                      # 사람이 실제로 확인한 것: 없음
def guard_by_argc(args):               # ⛔재는 것: 인자 개수
    return "REFUSED: 한 번에 여러 개" if len(args) >= 2 else f"OK: {args[0]}"
def guard_by_evidence(item, token):    # ⭕재는 것: 그 항목에서 나온 확인값
    want = hashlib.sha256(item.encode()).hexdigest()[:6]
    return f"OK: {item}" if token == want else f"REFUSED: {item} 확인값 불일치(요구 {want})"
looped = [guard_by_argc([i]) for i in ITEMS]
tokens = {i: (hashlib.sha256(i.encode()).hexdigest()[:6] if i in confirmed else "000000") for i in ITEMS}
ev = [guard_by_evidence(i, tokens[i]) for i in ITEMS]
r_loop = sum(r.startswith("REFUSED") for r in looped)
r_ev   = sum(r.startswith("REFUSED") for r in ev)
print(f"한 번에 {len(ITEMS)}개 ⇒ 거부 {1 if guard_by_argc(ITEMS).startswith('REFUSED') else 0}/1")
print(f"루프로 1개씩 ⇒ 거부 {r_loop}/{len(ITEMS)}   ← 처리된 것 {len(ITEMS)-r_loop}")
print(f"증거 기반 ⇒ 거부 {r_ev}/{len(ITEMS)}")
bad = len(ITEMS) - r_loop
print(f"🔴 가드가 서 있는데 확인 없이 처리된 건: {bad}건")
sys.exit(1 if bad else 0)
```
```
[측] 출력 : 한 번에 ⇒ 1/1 · ★루프 ⇒ ★0/5(처리 5) · 증거 기반 ⇒ 5/5  ⇒ rc ★1
```

## ⑥ 처방
```
① ★가드를 달기 前에 ★한 문장으로 적는다 : ***「나는 ★무엇을 막고 싶은가」***
   ⇒ 그 문장과 ★조건식을 ★나란히 놓는다 — ★다르면 ★조건식이 틀린 것
② ★확인을 ★비싸게 만든다 : ***★그 항목의 내용에서 나온 값***을 요구(⛔플래그 이름은 근거가 아니라 문자열)
③ ★시간창 안 호출 횟수를 센다 — ★한 번에 N개든 ★N번 한 개든 ★같은 수가 되게
④ ★거부 ★0 을 ★초록으로 읽지 않는다 — ***★0 은 「안 걸렸다」이지 「없었다」가 아니다***
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★②의 확인값은 ★다른 도구도 「채워져 있으니 통과」로 쓸 수 있다 ⇒ ★형태 검사를 같이 건다.
> ⇒ (같은 계열 함정 : ★값의 ★길이를 증거로 읽는 검사)
> ```

## ⑦ 이 카드가 주장하지 않는 것
```

⛔ 「증거 기반이면 끝」 — ★확인값을 ★자동으로 채우면 ★같은 자리로 돌아온다
