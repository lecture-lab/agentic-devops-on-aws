# 🃏 CARD-004 — ***처방에는 권한이 없다***

> 함정 카드 · 재료 · 2026-09-16
> 🔒 밟아야 생기는 함정입니다. 그래서 ⑤에 **붙여넣어 돌릴 것**을 답니다.

## ① 제목 (기전으로)
**점검 도구가 「이렇게 고치십시오」를 내미는데 — 그 도구는 지금 무엇이 금지돼 있는지 모른다.**
⇒ 사람은 *진단*을 신뢰한 김에 *처방*까지 신뢰한다. **둘은 다른 권한이다.**

## ② 겉보기
```
· 아침 점검이 빨강 하나를 띄우고 ★친절하게 다음 명령을 적어준다.
· 그 명령은 ★정확하고 · ★그 증상에 맞고 · ★복사해서 붙이면 잘 돈다.
· 아무도 묻지 않는다 — ***「이 명령을 지금 ★내가 해도 되는가?」***
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 금지 목록에 든 연산 ★3 · 점검기가 낸 소견 ★3 · 그중 ★처방이 붙은 것 ★3
· 순진한 점검기 ⇒ ***★금지된 수를 ★2건 처방*** (2/3)
· 게이트 통과 後 ⇒ 금지 2건은 ★처방 대신 ★🛑 표시 · 허용 1건만 처방
· 정책을 ★못 읽을 때 ⇒ ★3건 ★전부 ★처방 없음(fail closed)
· 아래 ⑤ 재현 rc ★1
```

## ④ 기전
진단기는 **자기가 보는 면**(신선도·크기·시각)만 안다. 금지는 **다른 면**(정책·사건·심사)에서 온다.
두 면이 만나는 자리가 없으면, 도구는 *언제나* 최선의 처방을 낸다 — **그 처방이 지금 금지돼 있어도.**
그리고 사람은 도구의 **진단이 맞았기 때문에** 처방도 맞다고 읽는다.
⇒ 🔒 ***진단의 정확성은 처방의 권한을 보증하지 않는다.***

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```python
import sys
ACTIVE_PROHIBITIONS = {"index_rebuild", "index_search", "bulk_delete"}
FINDINGS = [
    {"id":"f1","symptom":"색인이 낡음","remedy_op":"index_rebuild"},
    {"id":"f2","symptom":"임시파일 누적","remedy_op":"tmp_cleanup"},
    {"id":"f3","symptom":"검색 결과 불일치","remedy_op":"index_search"},
]
def emit_naive(f):  return f"⇒ {f['remedy_op']} 하십시오"
def emit_gated(f, policy):
    if policy is None:                 return "⏸ 정책을 못 읽었습니다 — 처방 없음(fail closed)"
    if f["remedy_op"] in policy:       return f"🛑 {f['remedy_op']} 는 현재 금지 — 처방하지 않습니다"
    return f"⇒ {f['remedy_op']} 하십시오"
naive = {f["id"]: emit_naive(f) for f in FINDINGS}
bad = [f["id"] for f in FINDINGS
       if f["remedy_op"] in ACTIVE_PROHIBITIONS and naive[f["id"]].startswith("⇒")]
print("순진한 처방:", naive)
print("게이트 後 :", {f["id"]: emit_gated(f, ACTIVE_PROHIBITIONS) for f in FINDINGS})
print("정책 못 읽음:", {f["id"]: emit_gated(f, None) for f in FINDINGS})
print(f"🔴 금지된 수를 처방한 건: {bad} ({len(bad)}건/{len(FINDINGS)})")
sys.exit(1 if bad else 0)
```
```
[측] 출력 : 금지된 수를 처방한 건 ['f1','f3'] ⇒ ★2/3 · rc ★1
```

## ⑥ 처방
```
① 금지 목록을 ★기계가 읽는 자리에 둔다 — ⛔산문이 아니라 ★목록
② 도구가 ★명령을 제안하는 ★모든 출구에서 ★대조한다 — ⛔한 곳만 막으면 나머지가 옛 뜻으로 낸다
③ 목록이 ★없음·낡음·깨짐·못 읽음 ⇒ ***★처방을 안 낸다***(fail closed) — ⛔「일단 권고」 금지
④ 목록은 ★도구가 ★쓰지 않는다 — ★소유가 갈라져야 ★자기 면제를 못 쓴다
⑤ 출력에 ★진단과 ★처방을 ★시각적으로 가른다 — 사람이 ★두 권한을 ★한 줄로 안 읽게
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★금지 목록은 ★다른 도구의 ★입력이기도 하다. 한 파일을 ★여러 도구가 읽으면
> ⇒ 그 파일이 ★낡았을 때 ★전부가 동시에 틀린다 ⇒ ★신선도 자체를 ★③의 fail-closed 조건에 넣는다.
> ```

## ⑦ 이 카드가 주장하지 않는 것
```
⛔ 「도구가 처방을 내면 안 된다」 — 아니다. ★권한을 확인하고 내면 된다
⛔ 「진단이 틀렸다」 — ★진단은 맞았다. ***맞았기 때문에 더 위험했다***
⛔ 「사람이 조심하면 된다」 — ⛔같은 사람이 ★두 번 밟았다면 그건 ★규율 문제가 아니라 ★구조 문제다
⛔ 「게이트를 붙이면 끝」 — ★목록이 낡으면 ★게이트도 낡는다(⑥의 ⚠️ 참조)
```
