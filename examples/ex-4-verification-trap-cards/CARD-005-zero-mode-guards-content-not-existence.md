# 🃏 CARD-005 — ***0000 은 읽기를 막지 존재를 지키지 않는다***

> 함정 카드 · 재료 · 2026-09-17
> 🔒 밟아야 생기는 함정입니다. ⑤는 **붙여넣어 돌리면 빨강**입니다.

## ① 제목 (기전으로)
**파일 권한은 「그 파일의 내용」을 지키고 · 「그 이름이 존재하는가」는 ★부모 디렉터리가 정한다.**
⇒ `chmod 000` 을 걸어놓고 «잠갔다»고 적으면 — **지워지고 같은 이름으로 대체되는 것**을 못 막는다.

## ② 겉보기
```
· 중요한 파일에 ★0000 을 건다. 읽어보면 ★Permission denied — ★잠긴 것처럼 보인다.
· 점검 스크립트도 「읽기 ⛔ · 쓰기 ⛔」 ★두 줄만 찍고 ★초록을 낸다.
· ⊥ ★내용은 ★바뀌어 있다. ★같은 경로 · ★같은 이름 · ★다른 바이트.
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 파일 mode ★0 · 부모 mode ★755 (⛔그룹 쓰기 ★없음 — ★그룹 비트와 무관하다)
· ① 읽기   ⇒ Permission denied      · ② 쓰기 ⇒ Permission denied
· ③ ★삭제 ⇒ ***★성공***             · ④ ★재생성 ⇒ ***★성공*** (내용이 `ATTACKER` 로 교체)
· 재현 rc ★1
```

## ④ 기전
`unlink()` 와 `create()` 가 검사하는 것은 **대상 파일의 mode 가 아니라 ★그 파일이 들어 있는 디렉터리의 쓰기권**이다.
파일 mode 는 **열기(open)** 를 막는다. 그래서 0000 은 *내용 읽기·쓰기*를 정확히 막지만,
**이름을 지우고 새 파일을 같은 이름으로 놓는 경로**에는 관여하지 않는다.
⇒ 🔒 ***「막았다」를 ★동사 없이 적으면 ★절반만 참이다*** — 읽기·쓰기·삭제·교체는 **다른 문**이다.

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```sh
d=$(mktemp -d); mkdir -p "$d/vault"; chmod 755 "$d/vault"
printf 'SECRET\n' > "$d/vault/key"; chmod 000 "$d/vault/key"
echo "파일 mode=$(stat -c %a "$d/vault/key")  부모 mode=$(stat -c %a "$d/vault")"
printf '① 읽기  : '; cat "$d/vault/key" 2>&1 | sed 's/.*: //'
printf '② 쓰기  : '; (echo x >> "$d/vault/key") 2>&1 | sed 's/.*: //'
printf '③ 삭제  : '; rm -f "$d/vault/key" && [ ! -e "$d/vault/key" ] && echo "성공 — 파일이 사라졌습니다"
printf '④ 재생성: '; printf 'ATTACKER\n' > "$d/vault/key"; cat "$d/vault/key"
if [ "$(cat "$d/vault/key" 2>/dev/null)" = "ATTACKER" ]; then
  echo "🔴 0000 인데 내용이 바뀌었습니다 — 읽기만 막혔습니다"; rm -rf "$d"; exit 1
fi
rm -rf "$d"; exit 0
```
```
[측] 출력 : ① Permission denied · ② Permission denied · ③ ★성공 · ④ ★ATTACKER  ⇒ rc ★1
[🪞측] ★첫 판은 ★판정 줄을 빠뜨려 ★카드 코드가 rc ★0 이었습니다 — ***★카드에서 꺼내 돌려서 잡았습니다***
```

## ⑥ 처방
```
① 「막았다」를 ★동사별로 적는다 : ★읽기 ⊥ ★쓰기 ⊥ ★삭제 ⊥ ★교체 — ⛔한 낱말로 덮지 않는다
② 존재를 지키려면 ★부모의 custody 를 본다 — ★파일 비트로는 ★안 된다
③ 점검기는 ★네 동사를 ★네 줄로 찍는다 — ⛔「잠김 ⭕」 한 줄 금지
④ 진짜로 교체를 막아야 하면 ⇒ ★부모를 ★다른 주체가 소유하거나 · ★불변 속성(플랫폼 기능)을 쓴다
   ⚠️ ★같은 사용자 안에서는 ★어느 쪽도 ★스스로에게는 안 듣는다 — ★그 사실을 ★적어둔다
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★「mode 를 본다」는 점검은 ★여러 곳에 흩어져 있다 — ★한 곳만 네 동사로 고치면
> ⇒ ★나머지가 여전히 ★한 낱말로 초록을 낸다 ⇒ ★mode 를 읽는 자리를 ★전부 세고 시작한다.
> ```

## ⑦ 이 카드가 주장하지 않는 것
```
⛔ 「0000 은 쓸모없다」 — ⛔아니다. ★읽기는 ★진짜로 막힌다(★그게 목적이면 ★유효하다)
⛔ 「부모를 조이면 끝」 — ★같은 사용자면 ★소유자가 그대로 지운다
⛔ 「그룹 비트 문제」 — [측] 부모가 ★755(그룹 쓰기 ★없음)여도 ★똑같이 지워졌다
⛔ 「특권 계정도 막힌다」 — ★특권 계정은 ★mode 밖이다
```
