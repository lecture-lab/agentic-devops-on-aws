# 🃏 CARD-009 — ***금지목록은 내가 떠올린 것까지만 막는다***

> 함정 카드 · 재료 · 2026-09-23
> 🔒 밟아야 생기는 함정입니다. ⑤는 **붙여넣어 돌리면 빨강**입니다.

## ① 제목 (기전으로)
**「위험한 것들을 걸렀다」는 검사는 ★작성자의 상상을 상한으로 갖는다.**
⇒ 허용형(allowlist) 하나는 **상상 밖까지** 막는다. 금지목록(denylist)은 **떠올린 만큼만** 막는다.
⇒ 그리고 떠올리기 가장 어려운 것은 *이상하게 생긴 문자*가 아니라 **정규화 애매성**이다.

## ② 겉보기
```
· 식별자를 경로 성분으로 쓰기 前에 ★검사를 붙였다 — 「`..` 과 `/` 를 거른다」
· 그럴듯하다. ★경로 탈출의 교과서 두 가지를 ★정확히 막는다.
· 자체 시험 ★전부 초록. ★탈출 시도는 ★거부된다.
· ⊥ ★대문자 한 번 · ★공백 한 칸 · ★전각 숫자 · ★빈 문자열이면 ⇒ ***★그대로 통과***한다.
```

## ③ 기계가 낸 수 (⛔형용사 없음)
```
· 적대 값 ★15 에 대고
    금지목록판(`".." 없음 ＋ "/" 없음`)  ⇒ ★통과 ***8***
    허용형판(`\A[0-9a-f]{16}\Z`)        ⇒ ★통과 ***0***
· 통과해버린 ★8 : 역슬래시 · 점 하나 · 빈 문자열 · 과길이 · 대문자 hex
                 · 공백 패딩 · ★전각 숫자 · ★NUL 바이트
· 정상 값 하나는 ★양쪽 다 통과 ⇒ ⛔허용형이 ★일을 막고 있지 않음을 ★같이 보인다
· 재현 rc ★1
```
⚠️ **실제 사고에서의 모양** — 검사가 아예 없던 판에서, 식별자에 `../X` 를 넣자
설치가 ***성공***으로 끝나고 · **선언해둔 두 디렉터리는 항목 0** · 파일 셋은 **뿌리에** 생겼다.
뿌리 억제 검사는 **있었고 · 통과했다** ⇒ 🔒 ***「밖으로 못 나간다」는 「제자리에 있다」가 아니다.***

## ④ 기전
금지목록은 **목록을 쓴 사람의 머릿속**이 상한이다. 그래서
*떠올리기 쉬운 것*(`..`, `/`)은 막히고 — *떠올릴 이유가 없던 것*은 남는다.
남는 쪽에는 **같은 것의 다른 표기**가 몰려 있다: 대소문자, 공백, 전각/반각, 유니코드 정규화, 빈 값, 길이, 형(type).
⇒ 허용형은 **「무엇이 허용되는가」 한 문장**이라 — 표기가 몇 가지든 **셀 필요가 없다**.
⇒ 🔒 ***금지목록의 상한은 내 상상이고 · 허용형의 상한은 규격이다.***

## ⑤ 재현 (붙여넣어 돌리면 ★빨강)
```python
import re, sys
HOSTILE = [
    ("경로 상위",   "../ESCAPE"),              ("경로 중간",   "aaaaaaaa/../bbbbbbbb"),
    ("슬래시",     "aaaaaaaa/bbbbbbbb"),       ("역슬래시",   "aaaaaaaa\\bbbbbbbb"),
    ("절대경로",   "/0123456789abcdef"),       ("점 하나",    "."),
    ("점 둘",      ".."),                      ("빈 문자열",  ""),
    ("비문자열 정수", 1234567890123456),        ("비문자열 None", None),
    ("과길이",     "0123456789abcdef" * 8),    ("대문자 hex", "0123456789ABCDEF"),
    ("공백 패딩",  " 0123456789abcdef "),      ("전각 숫자",  "０１２３４５６７８９ａｂｃｄｅｆ"),
    ("NUL 바이트", "0123456789abcde\x00"),
]
GOOD = "0123456789abcdef"                      # ★생성기가 내는 모양

def deny(x):        # 🔴 떠올린 금지목록 — 「`..` 과 `/` 를 거른다」
    return isinstance(x, str) and ".." not in x and "/" not in x

ALLOW = re.compile(r"\A[0-9a-f]{16}\Z")        # ⭕ 허용형 하나 — ★앵커 포함
def allow(x):
    return isinstance(x, str) and ALLOW.match(x) is not None

leaked = [n for n, v in HOSTILE if deny(v)]
blocked_by_allow = [n for n, v in HOSTILE if not allow(v)]
print(f"적대 값 {len(HOSTILE)}")
print(f"  금지목록 통과 : {len(leaked)}  ⇒ {leaked}")
print(f"  허용형 통과   : {len(HOSTILE) - len(blocked_by_allow)}")
assert allow(GOOD) and deny(GOOD), "정상 값은 양쪽 다 통과해야 합니다(⛔허용형이 일을 막으면 안 됨)"
print(f"  정상 값 {GOOD!r} ⇒ 금지목록 {deny(GOOD)} · 허용형 {allow(GOOD)}")
if leaked:
    print(f"🔴 금지목록이 통과시킨 적대 값 {len(leaked)}건")
sys.exit(1 if leaked else 0)
```
```
[측] 출력 : 금지목록 통과 ★8 · 허용형 통과 ★0 · 정상 값은 ★양쪽 통과 ⇒ rc ★1
```

## ⑥ 처방
```
① ★허용형 하나를 ***★규격에서 가져온다*** — 예: ★생성기가 내는 모양 그대로
② ★앵커를 빠뜨리지 않는다(`\A…\Z`) — ⛔`match` 만 믿으면 ★꼬리가 남는다
③ ★형(type)·빈 값·길이를 ***★같은 검사 안에서*** 처리한다 — ⛔따로 두면 ★따로 잊는다
④ ★경로를 만들기 ***★前에*** 잰다 — ★만든 뒤의 억제는 ★다른 물음에 답한다
⑤ ★억제 검사는 ***★겹 방어로 남긴다*** — ⛔그것을 ★검증기로 쓰지 않는다
⑥ ★약화 돌연변이를 ★따로 돌려 ***★통과 수를 세어 보인다*** — ⛔「막았다」를 ★말로 두지 않는다
```
> ⚠️ **이 처방이 쓰는 재료를 다른 검사도 쓰고 있지 않은가**
> ```
> ★허용형을 좁히면 ★기존 값 中 ★규격 밖이던 것이 ★전부 빨강이 된다.
> ⇒ ★그게 ★정상이다. ⛔그 빨강을 ★「검사가 빡빡하다」로 읽고 ★넓히지 않는다.
> ⇒ ★넓힐 거면 ***★규격을 먼저 바꾸고*** · ★검사는 ★규격을 따라간다.
> ```

## ⑦ 이 카드가 주장하지 않는 것
```
⛔ 「금지목록이 항상 나쁘다」 — ★허용형을 쓸 수 없는 자리(자유 문장·본문)에서는 ★그것뿐이다
⛔ 「허용형이면 안전」 — ★허용형이 ★틀린 규격을 베끼면 ★그 규격만큼만 맞다
⛔ 「8이 이 함정의 크기」 — ★8 은 ***★내가 적어본 적대 값 15 안에서의 수***다. ★분모는 ★내 목록이다
⛔ 「경로 주입을 다 막았다」 — ★막은 것은 ***★식별자라는 한 성분***이다. 다른 성분은 ★다른 검사가 본다
```
