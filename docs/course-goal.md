# Course Goal

You can code, but you have never deployed anything to a cloud provider
before, and you don't have a Solutions Architect or an MSP to hand this
to.

By the end of this course, one repository -- this one -- will have
grown from empty to a real, observable, alertable AWS deployment, built
with an AI coding agent that you supervised rather than trusted blindly.

You are not learning to memorize Terraform or AWS. You are learning to
review what an Agent proposes, approve what's safe, catch what isn't,
and know what to do when something breaks at 3am.
